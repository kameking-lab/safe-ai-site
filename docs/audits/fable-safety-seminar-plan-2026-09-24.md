**PR1 データスキーマ。** 既存フィールドは削除せず追加だけにします。墜落教材は型上 optional のため無変更で通ります。

```ts
type ArticleRef = {
  lawShort: "安衛法" | "安衛則" | "安衛令";
  article: string;        // 例 "第28条の2"
  sourceId: string;       // registry の該当法令
  egovUrl: string;        // 基条は #Mp-At_N、枝番は法令トップ
  naviPath?: string;      // 例 "/law-navi/347AC0000000057/28-2"
};
type TrainingSlide = {
  // 既存フィールドはそのまま。以下を追加
  stage?: {
    headline: string;          // 36字以内
    keyPoints: string[];       // 3件以内、各16字以内
    caveat?: string;           // 30字以内。claimにcaveatがある枚は必須
    mascot?: { src: string; alt: string; width: number; height: number };
  };
  articleRefs?: ArticleRef[];  // 投影面に出すのは先頭2件まで
};
type QuizQuestion = {
  // 既存 question/choices/correctIndex/explanation/claimIds はそのまま
  choiceRationales: string[];  // 4件。20〜80字。正解にも理由を書く

};
quiz.version: string;          // 進捗保存キーに使う
```

**投影面の画面仕様。** ステージに出す要素はこの順で固定します。章見出し、表題、要点1文、キーポイント3件以内、右側にチワワ、限定条件行、根拠チップ、ページ番号。既存の `message` と `body` はステージから外し「詳しく」に移します。限定条件は短文化で落とさず、`caveat` 行として常時表示し、全文は「詳しく」に置きます。対象は4枚目の将来施行条文、5枚目の第30条一律適用禁止、10枚目の法定教育非代替です。

**操作。** ステージ下の操作は前へ・再生/一時停止・次へ・全画面の4つと「12枚」一覧チップの5つに減らします。字幕は再生中だけ自動表示し、トグルは「詳しく」内のチェックボックスへ移します。Cキーは残します。「音声原稿を読む」は「詳しく」に改名し、本文・原稿・講師補足・根拠一覧を1つの引き出しにまとめます。キーボード案内はlg以上だけ表示します。音声は残します。12本の音声が存在し、講師不在の朝礼投影で唯一の差別化要素だからです。自動再生は引き続き禁止です。

**条文直リンクの扱い。**
- 基条は既存方針どおり `https://laws.e-gov.go.jp/law/{法令番号}#Mp-At_{N}` を使います。`permalink.ts` と `egov-fallback.ts` が実測有効としている形です。
- 枝番条の第28条の2・第29条の2・第31条の4は、内部の法令ナビ条ページを第一リンクにします。安衛法の第1・3・4・28条の2・29・30・59・61条は curated 収録を確認済みです。e-Gov側は法令トップにします。コード内には `#Mp-At_64_2` 形式の使用例もありますが、`permalink.ts` は枝番を法令トップに落とす方針です。実ブラウザで着地を確認し監査docに記録した場合だけ枝番アンカーを許可します。
- 安衛法教材に安衛則の条文は現状ありません。PR1で新しい条文を追加しないでください。追加が必要ならe-Gov原文の引用を添えてオーナー承認を取り、PR2以降で行います。
- 厚労省指針と改正法PDFは既存URLのまま、locator を表示文にします。
- 安全法令ダイジェストは構成の参考に限り、URLも書名も出典欄に載せません。

**PPTX/PDF 同期方針。** ファイル名とパス、12枚構成、ノートの原稿・claim ID・出典行は維持します。投影面は `stage.*` を正本にし、`body` はノートへ移します。脚注の根拠は `articleRefs` から生成し、正規表現抽出は廃止します。ノートの `[Sources]` に条アンカーURLを1行ずつ追加します。各枚のマスコットは右下に固定配置し、表紙はシーン画像のままにします。PDFはPPTXから同一手順で作り、その手順を `docs/training/` に固定します。生成後のSHA-256を監査docに記録し、`storage-deployment-guard` の既存許可パスの範囲内に収めます。Sol環境で `SKILL_DIR` などが無い場合は、PR本文にその旨を書き、オーナー再生成を完了条件にします。

**クイズの状態遷移。** URLは増やしません。AGENTS.md が `/e-learning/exams` と `/exam-quiz` の生成を禁止しているため、教材ページ内の部品として実装します。
1. 導入。進捗0/5、保存があれば「続きから」と「最初から」を出す。
2. 出題。選択肢は4つのボタン。正解は画面に出さない。

## 3. 検証、ゲート、捨てる案、実装指示

**誤答理由と根拠リンクの検証は3層にします。**
- 機械検証。各問に理由4件、正解にも理由がある。理由の中の「第N条」は、その問の claim 文と registry の locator に含まれる条番号の部分集合であることを検証し、条文の発明を落とします。`ArticleRef` は `sourceId` が存在し、`egovUrl` が registry の URL を前置し、`naviPath` が `resolveLawNaviEntry` か全文解決で実在すること。URLは e-Gov と厚労省だけ。
- 人手検証。PR本文に「問・選択肢・理由・claim ID・locator」の表を載せ、労働安全コンサルタントであるオーナーが承認します。理由は claim 文の言い換えに限り、新しい法令解釈を書きません。
- 着地検証。全 e-Gov アンカーと内部条ページを実ブラウザで開き、該当条見出しが表示領域に入ることをスクリーンショットで `docs/audits/` に記録します。e-Gov はJS描画で自動化が不安定なため、この確認は手動で行います。

**意味のあるテスト。**
- データ。`stage` の文字量上限、caveat 必須枚、マスコット12枚一意、画像実在、原稿ハッシュがマニフェストの `narration_sha256` と一致すること。この一致テストで「原稿を変えたら音声を再生成する」を機械的に担保します。
- 部品。選択前に正解が DOM に無い、選択で採点と理由4件が出る、次問と結果と誤答再挑戦が動く、再読込で進捗が復元される。
- プレイヤー。操作ボタンが5つ、根拠チップの href が e-Gov か法令ナビ、「詳しく」に本文と原稿と講師補足が出る、自動再生しない。
- E2E。`safety-seminars.spec.ts` に安衛法教材を追加し、4幅のはみ出し、クイズ完走、axe、JS無効の静的表示、配布物200とサイズを確認します。390pxスモークにも同ページを追加します。
- 配布物。PPTX12枚、ノートに条アンカーURL、PDF12頁とタイトルメタ、私有情報の不在、PDF抽出文字列に `stage.headline` が全枚含まれること。

**公開前ゲート。** `tsc --noEmit`、lint、対象と全体の vitest、`npx next build`、`storage-deployment-guard --workspace`、E2E CI、public identity guard を順に通します。台帳が記録した既存 Lighthouse trace 7件による `audit:public-identity` の停止は今回の変更外なので、再現した場合は原因ファイルをPRで扱わず記録だけします。

**本番確認。** 安衛法教材ページで音声12本と PPTX と PDF が200と Content-Length を返す、クイズ5問を実機スマホで完走、e-Gov アンカー着地の再確認、Lighthouse mobile 90以上、監査docへの結果記録までを完了条件にします。

**捨てる案と理由。**
- クイズ採点のサーバー化や Supabase 保存。AGENTS.md の DB 本接続禁止に反し、localStorage で足ります。
- クイズ専用URLの新設。AGENTS.md が明示的に禁止しています。
- PR1 での原稿改稿と音声再生成。オーナー機のローカル AivisSpeech とライセンス表示の再確認が要り、PR1 が完成しなくなります。
- 生成AIによる誤答理由の動的生成。法令内容のハルシネーション経路になります。静的でレビュー済みの JSON だけにします。
- 12枚全部の新規シーン画像。画像パイプラインは人手キュレーション前提で、PR1 では既存ポーズで要求を満たせます。
- 音声プレイヤーの撤去。12本の音声資産と講師不在の投影用途を捨てることになります。
- 字幕の完全撤去。再生中だけ自動表示に変えれば、ボタンを1つ減らしつつ価値を残せます。
- 枝番条の `#Mp-At_N_M` を未確認で採用すること。着地保証が無く、誤着地は法令正確性を損ないます。
- 安全法令ダイジェストや私有PDFのURL掲載。公開根拠になりません。
- 結果画面への相談CTA追加。サイクル1で除去した判断を覆します。
