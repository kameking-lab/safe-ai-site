# 墜落防止研修の確認クイズ共通化 — 2026-09-25

## 対象と判断

Astraの公開画面監査 `note-automation/reports/qualification-media-efficiency-20260924/ASTRA-PUBLIC-UX-GAPS-20260925.md` のP3を対象にした。墜落防止の既存5問の問題文・選択肢・正答・総括解説を維持し、基本安衛法教材で使用中の回答選択、即時採点、全4肢理由、進捗保存、誤答再挑戦へ接続した。新問は作っていない。保存キーは教材IDとクイズ版で分離する。

根拠は既存のe-Gov・厚生労働省source registryと、厚生労働省の検討会資料、労働安全衛生総合研究所の年報を使用した。最後の2件は原PDFを取得し、SHA-256をsource registryに記録した。検討会資料の吊り下がり時間は実験のばらつきを示す資料であり、法定の安全待機時間として扱わない。衝撃を受けた器具の再使用禁止は厚労省ガイドライン第7に対応する。

ページでは主配布形式をPowerPointとPDFの2点に絞り、講師台本など補助資料5点は展開欄にまとめた。20枚の教材、音声、原稿、法定教育を代替しない注意は維持した。

AstraによるPR #1010初回実画面レビュー後、墜落教材の字幕切替を主操作列から除き、5操作に統一した。字幕は墜落教材で常時表示し、基本教材の投影面ではスライド本文と再生中字幕を維持する。音声の選択UI・音声の出典表示は追加していない。根拠リンクには設問別locatorを併記し、安衛則の第36条/第521条と年報PDF84ページへ直接飛べるようにした。Q5のガイドラインlocatorは「第7の1（落下衝撃後の使用禁止）」に修正した。問題・正答・4肢理由は変更していない。
