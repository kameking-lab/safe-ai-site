# 安全看板ライブラリ UX 確認（2026-09-23）

対象は `web/src/app/(main)/materials/safety-images` の公開100点。

## 確認したこと

- 既存の編集画面は5言語をチェックボックスで同時選択でき、日本語が初期選択される。選んだ言語の文言は1枚の看板に上から順に入る。
- 全100点に A4/A3 の縦・横と各市場サイズが用意されている。今回、プレビューの直上に A4縦・A4横の切替を出した。サイズの詳細指定は従来どおり残した。
- 既存翻訳は `translation-registry.json` に検証状態が記録されている。全件がネイティブ確認済みという扱いにはしない。

## 修正

- 厚生労働省の[令和7年10月末の外国人雇用状況](https://www.mhlw.go.jp/stf/newpage_68794.html)で、全国の多い国籍はベトナム、中国、フィリピンの順。収録済みの言語を日本語、ベトナム語、中国語、英語、インドネシア語の順に表示する。英語はフィリピン語訳を意味しない。フィリピン語の未検証訳は追加しない。
- 一覧の言語チェックは100点すべてで同じ結果となり、向きチェックは完成品の用紙方向と紛らわしかったため、一覧から外した。言語は各看板の編集画面で選ぶ。
- 一覧は検索・カテゴリ・よく使う絞り込みを先に表示し、看板形式と用途は詳細条件へ入れた。カード内の重複した2ボタンは、画像とタイトルを含む1つのリンクに集約した。
- 編集画面では言語と文言を先に表示し、文字サイズ・色・位置・ロゴ・余白などの装飾設定とリセットを「詳細設定」にまとめた。
- 出力内容は3枚の選択カードから1つの選択欄にまとめ、初期値を「プレビューどおり」にした。文字や色を編集しても推奨版がダウンロードされる不一致を解消した。

## 受入確認

- 100点×A4縦横の200組について、既存5言語を同時に載せる文字配置を検査。
- 編集画面の用紙切替、言語選択、非公開の編集内容をURLに含めないことをテスト。
- Chromiumで一覧、5言語編集、320〜1440pxの表示を確認。

フィリピン語は100点に対応した確認済み訳がないため未収録。追加するときは全100点の文言と数値単位を独立確認する。
