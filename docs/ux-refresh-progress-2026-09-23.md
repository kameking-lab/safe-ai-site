# UX刷新 進捗台帳（2026-09-23）

## サイクル1

### 1. 実行した内容

- トップのチワワ導線を、安衛法AI・化学物質RA・日本国内の死亡事故・安全スライド・法改正の5機能へ集約した。
- 国内死亡事故の共通選別関数を追加し、トップ、`/accident-news`、`/api/signage-data` で同じ条件を使うようにした。死亡表現、国内の労働・工事事故表現、鮮度を必須とし、海外・非死亡・啓発記事を除外する。
- 保護具を15カテゴリのイラストカルーセルから選び、必要な特徴を確認してから販売サイトへ進む導線へ変更した。Amazonは4つ星以上の検索条件を付け、楽天と並べて比較できるようにした。
- 商品評価はサイト内の古い生成値を再掲せず、販売サイトの実画像・購入者評価を確認する方針とした。出典URL、リンク確認日、サイト内評価非掲載をデータ契約として追加した。
- NETISは重機接触・立入警報・AI人物検知・墜落防止・危険区域監視の検証済み5技術に加え、重機接触・立入禁止・墜落転落・暑熱環境の4画像カテゴリと、検索語・比較条件・製品解説を表示した。
- 安全看板は縦・横・正方形を画像選択前にボタンで選べるようにし、日本語を初期選択した5言語の複数チェックへ変更した。
- 戻る操作で直前ページのスクロール位置を復元する全体コンポーネントを追加した。pathname・クエリ・ハッシュ単位で位置を分離し、入力値は保存しない。
- 安全スライドから個人Google Driveリンク、音声訴求、公開画面の音声操作、相談CTA群を除去した。e-Govの安衛則第518条アンカーを優先し、各スライドへ異なるチワワ画像を割り当て、クイズを一問一答の根拠解説型として示した。
- 労災事例100003を厚労省原文に合わせ、松の木剪定中の脚立8段目（約2.3m）からの転落へ修正した。「5m以上」の誤った基準を安衛則第518条の2m基準へ是正した。
- `google-adsense-account=ca-pub-8751260838396451` を審査用の常時metaとして追加した。広告スクリプトは従来どおり同意後だけ読み込む。
- 事故統計ダッシュボードの詳細グラフ前に、死亡災害比率メーターと12か月ヒートマップを追加した。同じ集計値を確認できる代替表を折りたたみで併設した。
- 390×844pxのChromiumで、トップ・保護具・NETIS・安全看板・事故統計・安全スライドの6画面を確認するブラウザ監査を追加した。

### 3. 次に手を打つべき課題

- 商品の実画像をサイト内へ合法的・安定的に表示するには、販売事業者の画像利用条件と正式な商品APIを確認する。現状は販売サイトで実画像と最新評価を確認する。
- 安全スライド本文の文字量を全20枚で再計測し、法令上必要な限定条件を保ったまま投影用の短文へさらに整理する。

### 4. 人間の判断が必要な点

- 新しい有料の商品APIは導入していない。商品実画像をサイト内カルーセルへ直接表示する場合は、費用と利用規約の判断が必要。

## サイクル2：本番差分の再監査と修正

サイクル1の「成功」は当時の対象テスト・ローカル実装を指し、本番で全要件を満たした意味ではなかった。9月23日の本番照合では、ハイフォン市の重傷報道、音声選択、私有資料の公開出典、分離した機能入口が残っていた。この差分を優先して修正した。

- 事故速報の共通条件を「日本国内と見出しで確認できる労働中の死亡事故」に限定。海外、場所不明、重傷だけの見出しを除外し、トップ・事故速報・サイネージで共有した。キャッシュキーを更新した。
- チワワの下部に、安衛法AIと化学物質RAの直接入力、国内死亡事故、安全スライド、法改正の5機能をまとめた。スマホ実ブラウザで5入口と入力欄を確認した。
- スライドの音声種類・速度・音量・停止等の過剰な操作を除去。リダ音声モデルはクレジット表記がライセンス必須なので、プレーヤーから利用条件ページに移した。
- 私有Google Driveを公開ページと安全管理基本編のsource registryから除去。該当する3 claimをe-Gov安衛法・厚労省指針へ対応させ、配布PPTX/PDFも再生成した。PDF 12枚とPPTXの全XMLで私有資料名・Drive URLが残らないことを確認した。
- Next.jsのクライアント遷移前にスクロール位置を保存し、ホームへ戻ったとき復元するようにした。390pxの実ブラウザでホーム→保護具→戻るを通過した。
- 対象単体検証30件（8ファイル）、TypeScript型検査、390px幅の実ブラウザ1件が通過した。公開後の本番URL照合は別途記録する。

未完了：保護具の実商品写真・評価をサイト内に表示する正式データ契約、NETISの5件を超える掲載、全20スライドの文字量再編集、過去問AI式の回答・正誤判定・誤答復習を備えた確認クイズ。これらをサイクル1の完了欄へ繰り上げない。
