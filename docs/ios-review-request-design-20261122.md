# 安全AIポータル iOSの評価依頼設計

1.0.0（ビルド25）の審査承認後、1.0.1以降で実装する。

- 初回利用日を端末内に記録する。初回利用日を過ぎたうえで、化学物質RAの有効な結果が初めて表示された直後、または利用開始から5日目以降に朝礼ネタ本文を開いた直後を評価依頼の候補にする。
- 判定失敗、無料上限、購入フローの表示中、購入直後は呼び出しを見送る。候補が成立した時点でアプリが前面にあり、結果や本文を表示できたことを確認する。
- バージョンごとの呼び出し済みフラグを端末に記録し、2つの条件が重なっても1バージョンにつき最大1回、StoreKitの標準 `requestReview` を呼ぶ。表示するかどうかはOSが決める。利用日と呼び出し済みフラグに評価の点数や利用者情報は保存しない。
- 共有・評価は任意とする。機能の解放や特典の条件にせず、評価を選ばせる独自画面や評価に応じた誘導は作らない。
- 実装時は、初日、RAの判定成功・失敗、朝礼ネタの4日目・5日目、購入直後、同一バージョンでの再訪を確認する。確認対象は標準APIの呼び出し条件と回数。

[Apple App Reviewガイドライン（3.2.2(x)、5.6.1）](https://developer.apple.com/app-store/review/guidelines/)
