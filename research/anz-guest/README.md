# 未ログインAIの画面検証

- `iphone-guest-answer.png`：未ログインのまま安衛法チャットの回答を表示。
- `iphone-guest-limit.png`：日次無料枠の上限に対する429応答を受け、同じ画面に月額購入ボタンを1つ表示。
- 寸法：390×844 CSS px、上部セーフエリア59px。画像も390×844 pxで保存。
- テスト：`mobile/e2e/guest-ai.spec.ts`。空のKeychain、iOSプラグイン境界、サーバー応答をテスト用に再現し、アプリに同梱した本番ビルドのUI・ネイティブ送信アダプター・購入ログイン処理を実行。
- Chromium / WebKit / desktopで成功。購入前はログイン要求0件、無料枠を使い切った後は429、購入ボタンを押した後に初めてログイン要求1件。
- 実際のGemini呼び出し・App Store購入・実機操作・デプロイは行っていない。サーバーの共有無料枠、会員枠、費用予約と精算はVitestで別途検証。
- ag-1-rv 再検証：最終本番ビルドで関連E2E18件成功。撮影時は見出しを押して入力フォーカスを外し、Gemini処理の1行表示と下部ナビを確認してから、フォント・描画の完了を待つ。撮影条件追加後のゲストE2Eも3ブラウザ構成で成功。
- 保存画像はiPhone幅のWebKit。出力先はテストファイルの場所を基準に固定し、起動ディレクトリに依存しない。
