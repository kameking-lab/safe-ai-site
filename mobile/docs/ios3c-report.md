- **R2 アカウント削除**：会員画面に専用の開始・再ログイン・確認入力・確定・完了／処理状況確認を実装。直近5分の本人確認、セッションへの確認トークンの紐付け、確認期限、確認用トークンのハッシュ保存を行う。OAuthフローには実際のサインイン日時を記録し、古いブラウザセッションでの確認を拒否。確定時に全セッション・通知先・通知待ちデータを無効化する。Appleトークン失効後、会員・検索／学習／利用履歴・地点を削除。組織共有記録は作成者等を匿名化。購入所有者照合用の最小限の匿名取引情報は7年間保持する。外部処理失敗は完了扱いにせず、永続ジョブと受付証で再確認・再処理できる。端末保存とKeychainも削除する。購読解約は購入元で別途必要と明示した。

- **R4 二重購入防止**：購入元の異なる取消を拒否。クライアントの「取消済み」申告だけでは、開始済みのStoreKit予約を解除しない。Stripeは決済側で旧Checkoutを失効させた後に解除し、取消と完了の競合は購入完了として照合する。購入元をまたぐ競合と同じ予約の並行再開を回帰確認。成立後の重複は `DUPLICATE_PURCHASE_REVIEW` として記録する。
- **R5 表示設定**：ふりがな・やさしい日本語・文字大・屋外表示・テーマを全画面の共通設定に接続。ウェブ正本と同じ保存キーと表示処理を使う。画面移動・再起動・印刷メディア切替後の維持をE2E確認。サイネージ全画面では共通ヘッダーを隠す。共有URLに検索条件を含める。

- **R7 利用枠・復旧**：残10／50・2／10以下を強調し、日本時間の回復日時と処理中件数を表示。処理中で満杯の場合と本日の消費済み上限を区別。未送信の期限切れ予約のみ回収し、提供者送信済み・結果不明は保留する。提供者原価の予約は返却しない。5分の実行leaseと履歴の30日保持を分離し、保守処理が日次の消費済み履歴を早期削除しないよう修正。枠がなくてもAIを使わない法令検索・同梱資料へ進める。
